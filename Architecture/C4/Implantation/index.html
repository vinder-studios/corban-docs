SmartCorbans — Implantação

Onde cada container roda: as três aplicações como sites estáticos na Netlify, a API, o Worker e o job de migração no Azure Container Apps, e o PostgreSQL privado na mesma rede. Decisões nas ADR-0016 a ADR-0022.

v0.3 · DraftBase: Containers v0.2 · D-09 a D-11Azure · Netlify

Nós

NóServiçoO que roda
NetlifyTrês sites, um por app (ADR-0016)Build estático do Vite; regra de SPA; build filtrado por app no Turborepo.
Container Apps EnvironmentAzure Container Apps (ADR-0017), em VNetAPI com ingresso público, WebSocket e escala; Worker sem ingresso, uma réplica; job de migração manual.
PostgreSQLFlexible Server (ADR-0018), acesso privadoBanco único, um schema por módulo, backup automático.
Storage AccountBlob Storage (ADR-0024), sem acesso públicoLogo da Loja, Documentos do Cliente e da Proposta, arquivos de Lista. API e Worker por Managed Identity; o navegador envia e baixa por URL assinada.
Container RegistryACRImagens da API, do Worker e da migração.
Key VaultKey Vault + Managed Identity (ADR-0019)Segredos do Keycloak, AbacatePay, Huggy e webhooks. O banco não tem senha: a identidade gerenciada autentica no PostgreSQL.
Application InsightsApp Insights + Log AnalyticsLogs, métricas e traces da API e do Worker.

Rede e segurança

TemaComo fica
Entrada públicaSó a API, por HTTPS e WSS. Worker, migração e banco não são expostos.
CORSA API libera só os três domínios da Netlify.
WebhooksHuggy e AbacatePay entram pela mesma entrada pública, em rotas próprias, com validação de origem e idempotência.
BancoAcesso privado pela VNet, sem IP público.
SaídaHTTPS para os externos. NAT Gateway com IP fixo só se algum exigir lista de IPs (ADR-0020).
ArquivosBlob Storage privado; o navegador usa URL assinada de curta duração gerada pela API; CORS só para os três domínios da Netlify (ADR-0024).
SegredosSó no Key Vault, lidos por Managed Identity. Banco acessado sem senha (ADR-0019).
RegiãoBrazil South (ADR-0021), por causa dos dados pessoais e financeiros (RNF003).

Decisões

  • ADR-0016 Três sites na Netlify, em subdomínios do domínio da API.
  • ADR-0017 Azure Container Apps para API, Worker e migração.
  • ADR-0018 PostgreSQL Flexible Server com acesso privado; HA por zona desligada no início.
  • ADR-0019 Key Vault com Managed Identity; banco sem senha.
  • ADR-0020 NAT Gateway só se algum externo exigir IP fixo.
  • ADR-0021 Brazil South, a mesma região do sistema atual.
  • ADR-0022 Homologação com a mesma forma, descrita em código.

Fora deste diagrama

  • CI/CD: build das imagens, publicação no ACR e deploy dos sites.
  • Domínio e DNS: o diagrama usa api.<domínio> e um subdomínio por app.
  • Keycloak: continua na hospedagem atual (D-07). Se estiver na mesma Azure, a chamada da API pode passar a ser privada.
