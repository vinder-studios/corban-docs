Regras deste container

  1. Features só pelo index.ts; import profundo barrado pelo lint feature-deep-import.
  2. TanStack Query é o único contato com o estado do servidor; Zustand só para UI compartilhada.
  3. Mutações por serviços de domínio; consultas puras podem chamar data/api direto.
  4. MutationCache é o ponto único de toast de erro.
  5. Código em inglês; português só no texto para o usuário.
  6. Permissão na UI é conveniência; a API reaplica permissão e escopo.
