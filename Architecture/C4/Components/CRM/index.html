Diferenças em relação ao Admin

  • Tempo real: cliente WebSocket que invalida as consultas do TanStack Query e dispara notificações no Shell. Fica no app porque só o CRM usa.
  • Modo TV: rota pública, fora do Shell e sem login, aberta pelo link com token da Loja (RF-RNK-04).

Regras extras

  1. O Tempo real só invalida consultas; o dado novo vem da API.
  2. O Modo TV não usa sessão de usuário; só o token do link, só leitura dos Rankings marcados para TV.

As seis regras do Admin valem igual.
